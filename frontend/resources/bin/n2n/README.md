# N2P Binary Directory

To enable Version 2.0.0 P2P Networking, you MUST place the following files in this directory:

1. **edge.exe**: The N2N v3 client binary (Windows x64).
2. **wintun.dll**: The WinTun driver library (x64).

### Where to get them?
- **edge.exe**: You can find pre-compiled versions on GitHub (e.g., lucktu/n2n or similar community builds).
- **wintun.dll**: Download directly from https://www.wintun.net/

### Important
- Ensure the app is run as **Administrator** on Windows to allow these tools to create the virtual network interface.
